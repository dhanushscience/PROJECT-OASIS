FAQs //

Common questions

What is PROJECT OASIS?

An open-source BLE interface device with three configurable buttons and a Windows companion app for meetings, shortcuts, and automations.

How does it connect?

Bluetooth Low Energy via the companion app. USB-C handles charging and ESP32-C3 firmware updates.

Can I build my own?

Yes — KiCad PCB files, 3D enclosure models, and ESP-IDF firmware are in the GitHub repository.

Which apps are supported?

Any Windows application. Per-app profiles switch automatically when you change focus.
