FAQs //

Common questions about OASIS

What is PROJECT OASIS?

OASIS is an open-source BLE interface device with three configurable buttons and a Windows companion app. It brings tactile control to your desktop workflows — meetings, shortcuts, and automations.

How does OASIS connect to my PC?

The device pairs over Bluetooth Low Energy using the OASIS companion app. USB-C is used for charging and firmware updates on the ESP32-C3 microcontroller.

Which apps does OASIS work with?

Any Windows application. OASIS uses per-app profiles — when you switch to VS Code, Chrome, or a meeting app, your button mappings switch automatically.

Is the hardware open source?

Yes. PCB layouts, enclosure files, and firmware are available in the GitHub repository under open source hardware licensing.

Can I build my own OASIS?

Absolutely. The repository includes KiCad PCB files, 3D enclosure models, and ESP-IDF firmware. Flash the XIAO ESP32-C3 and pair with the Windows app.
